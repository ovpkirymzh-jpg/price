# Холодная вода — калькулятор оплаты (Android)

Считает оплату холодной воды без водоотведения:
`(текущие − предыдущие показания) × тариф`, округление до копеек.

- Тариф меняется прямо на экране и запоминается.
- Результат пересчитывается сразу при вводе. Запятая и точка в числах работают одинаково.
- Кнопка «Сохранить как предыдущие» переносит текущие показания в предыдущие для следующего месяца.

## Как получить APK

1. Установите Android Studio: https://developer.android.com/studio
2. File → Open → выберите папку `WaterCalc`, дождитесь окончания синхронизации Gradle.
   Если Studio предложит обновить Gradle или плагин Android, соглашайтесь.
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Файл появится здесь: `app/build/outputs/apk/debug/app-debug.apk`.
5. Скопируйте его на телефон и откройте. Если телефон попросит, разрешите установку из этого источника.

### Способ без Android Studio (через GitHub)

1. Создайте репозиторий на github.com и загрузите в него содержимое папки `WaterCalc`
   (вместе со скрытой папкой `.github`).
2. Откройте вкладку Actions — сборка «Build APK» запустится сама (или нажмите Run workflow).
3. Через 3–5 минут откройте завершённый запуск и скачайте `WaterCalc-apk` из раздела Artifacts.
   Внутри будет `app-debug.apk`, его нужно распаковать из zip и установить на телефон.

### Подключение телефона по USB

Либо подключите телефон по USB (с включённой отладкой) и нажмите Run ▶ — приложение установится само.

Из командной строки: `./gradlew assembleDebug` (нужны JDK 17 и переменная `ANDROID_HOME`).

## Параметры

Минимальная версия Android — 8.0 (API 26). Идентификатор приложения — `com.example.watercalc`;
его можно сменить в `app/build.gradle.kts` (`applicationId` и `namespace`).
